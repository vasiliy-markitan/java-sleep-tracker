# java-sleep-tracker

Приложение, которое поможет людям проанализировать записи о своём сне и организовать его более здоровым образом.

## ФТ к функционалу:

### Входящие параметры. Логи сна

У пользователя есть устройство для съема логов сна.
Записи в файле упорядочены по дате и времени.

#### Атрибутивный состав логов
 
Лог складывается в формате: «дата и время засыпания, дата и время пробуждения и качество сна».

Пример:
```plain
01.10.25 22:15;02.10.25 08:00;GOOD
02.10.25 23:00;03.10.25 08:00;NORMAL
03.10.25 14:30;03.10.25 15:20;NORMAL
03.10.25 23:30;04.10.25 06:20;BAD
```

Формат лога "dd.MM.yy hh:mm:ss;dd.MM.yy hh:mm:ss;"
Качество - оценивается часами автоматически на основе количества телодвижений во время сна, а также анализе частоты дыхания и сердцебиения, и может принимать одно из трёх значений: GOOD (хорошее), NORMAL (нормальное), BAD (плохое)



### Обработка данных

UC: Анализировать сон пользователя и давать ему в понятном виде информацию о проблемах в его сне и, возможно, некоторые рекомендации для его улучшения.

Приложение будет предоставлять набор аналитических функций для анализа лога сна. 
Каждая из функций отвечает на определённый вопрос, например сколько раз за рассматриваемый период пользователь спал недостаточно. 

Нефункциональные требования: 
1) расширяемость - обеспечить легкое добавление новых аналитических функции, не изменяя основной код приложения.
2) функциональная разработка. конструкции вида for, while - запрещены в коде приложения
